## موارد مسدودکننده انتشار رسمی

1. اجرای `npm install` و ثبت `package-lock.json` برای نصب تکرارپذیر.
2. اجرای موفق `npm run check`، `npm run build` و `npm run test:e2e` روی Node 22.
3. تولید PDF فارسی با فونت مجاز، بررسی بصری اتصال حروف، RTL، سطرها، اعداد و صفحه‌بندی.
4. بررسی فایل DOCX در Word/LibreOffice، از جمله نمودارها و جداول راست‌به‌چپ.
5. بررسی تصاویر خروجی تست مرورگر، کنتراست، فوکوس و صفحه موبایل.
6. بررسی وابستگی‌ها و ثبت نتایج CI یا اجرای مستقل؛ محدودیت Billing ممکن است CI را متوقف کند.

## دستورات Windows PowerShell

```powershell
git checkout main
git pull
git checkout -b verify/v1-local
npm install
npm run check
npm run build
npx playwright install chromium
npm run test:e2e
npm audit --omit=dev
```

**نکته:** این دستورات را پس از Merge اصلاحات اجرا کن. در این محیط امکان دریافت بسته‌های npm و اجرای تست یکپارچه روی نسخه GitHub فراهم نبود. هیچ نتیجه PASS یا انتشار رسمی ادعا نشده است.
