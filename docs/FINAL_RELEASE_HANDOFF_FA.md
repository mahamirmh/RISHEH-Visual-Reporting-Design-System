# تحویل نهایی مسیر آموزشی RISHEH Visual Reporting

## آنچه تحویل داده شده است

مسیر آموزشی شامل ۱۰ درس تشریحی، ۲۶ مدخل فرهنگ اصطلاحات، ۲۶ تصویر SVG قابل ویرایش، اطلس تصویری، تمرین‌ها، راهنمای توسعه‌دهنده و دفترچه QA است. نمونه‌ها بر پایه محصول خیالی «آوا» هستند؛ هیچ ادعایی درباره داده مشتری ندارند.

## معیارهای پایان کار

| Gate | روش | وضعیت |
|---|---|---|
| E1 — پیوندها و ساختار آموزش | `npm run qa:education` | نیازمند اجرای ثبت‌شده |
| E2 — رندر ۲۶ تصویر در سه اندازه | `npm run qa:visual` | ابزار آماده؛ نیازمند اجرای ثبت‌شده |
| E3 — بازبینی انسانی ۷۸ اسکرین‌شات | `test-results/education-visual/*.png` | نیازمند تأیید |
| E4 — تطبیق متن با تصویر | بررسی درس‌ها و واژه‌نامه | بازبینی متنی انجام شده؛ تأیید بصری باقی است |
| E5 — تست‌های کد و خروجی‌ها | `npm run check && npm run build && npm run test:e2e` | نیازمند اجرای ثبت‌شده |
| E6 — کیفیت فارسی PDF و Word | رندر و مشاهده خروجی واقعی | نیازمند تأیید |

**تعریف DONE:** تمام Gateهای مربوط به محدوده استفاده باید PASS باشند و شواهد آن‌ها در گزارش انتشار ثبت شود. بدون شواهد، عبارت «پروژه کاملاً تأیید و بسته شد» صحیح نیست.

## دستور یکپارچه اجرا

در یک محیط توسعه با Node.js 22، وابستگی‌ها و مرورگر Chromium:

```bash
npm install
npx playwright install chromium
npm run qa:release
```

اگر فقط بخش آموزشی بررسی می‌شود:

```bash
npm run qa:education
npm run qa:visual
```

**خروجی قابل ممیزی:** فایل `test-results/education-visual/report.json` و ۷۸ اسکرین‌شات در همان پوشه. اگر GitHub Actions در دسترس باشد، workflow با نام **Education visual release QA** همین خروجی‌ها را به‌عنوان Artifact ذخیره می‌کند. خطای Billing یا نبود Runner به معنی شکست یا موفقیت کد نیست؛ در آن حالت باید اجرای محلی ثبت شود.

## بازبینی نهایی انسان

در تصاویر Wireframe، Mockup و Prototype یک صفحه مشترک را مقایسه کنید. در نمودارها، عددها، عنوان‌ها و برچسب‌ها را با توضیح متن تطبیق دهید. در موبایل ۳۶۰ و ۳۹۰ پیکسل و دسکتاپ ۱۴۴۰ پیکسل، خوانایی نوشته‌ها، نبود بریدگی، هم‌پوشانی و اندازه مناسب را بررسی کنید. برای خطا، نام فایل، عرض نمایش، اسکرین‌شات و شرح اختلاف را ثبت کنید.

## تصمیم انتشار

- **برای مطالعه داخلی تیم:** محتوا و نمونه‌های آموزشی در مخزن قابل دسترسی‌اند؛ می‌توان آن‌ها را با برچسب «آموزشی / داده ساختگی» استفاده کرد.
- **برای استفاده کد در پروژه مشتری:** تا زمان عبور از Gateهای فنی و کنترل PDF/DOCX فارسی، انتشار Production تأیید نشده است.
- **وضعیت فعلی:** مسیر مستندسازی و ابزارهای QA تحویل داده شده‌اند؛ **تأیید نهایی عملیاتی مشروط به اجرای آزمون‌ها و بازبینی اسکرین‌شات‌هاست**.

## مسئولیت نگهداری

در هر تغییر آینده روی درس، واژه‌نامه یا SVG باید `qa:education` و `qa:visual` اجرا شود. افزودن اصطلاح جدید نیازمند به‌روزرسانی اطلس، توضیح قابل فهم، مثال بصری، متن جایگزین و آزمون رگرسیون است. تغییرات بدون سند آزمون نباید «Visual QA Passed» نامیده شوند.
