# Report templates

1. Executive Brief: summary, KPIs, decisions, risks, sources.
2. Engineering Audit: scope, evidence, severity, remediation, verification.
3. Product Discovery: problem, audience, hypotheses, journey, experiments.
4. UX Review: context, screenshots, issues, accessibility, recommendations.
5. Research Review: question, methods, findings, limitations, references.
6. Operations: SLA/SLO, trends, incidents, action owners.
7. Proposal: brief, solution blueprint, timeline, deliverables, assumptions.
8. Case Study: challenge, approach, implementation, outcomes, evidence.

Each template is a composition guideline, not a license to fabricate results.
