# فرهنگ اصطلاحات / Glossary

| Term | تعریف فارسی |
|---|---|
| Brief | شرح فشرده مسئله، هدف، مخاطب و محدودیت‌ها |
| Blueprint | نقشه جامع اجزا، روابط و اجرای یک سیستم |
| Chart | نمایش گرافیکی داده‌های کمی |
| Graph | نمودار روابط یا داده‌ها بسته به زمینه |
| Diagram | نمایش شماتیک ساختار یا فرایند |
| Flowchart | نمایش مراحل و نقاط تصمیم |
| Wireframe | طرح اولیه ساختار صفحه |
| Mockup | نمایش بصری نسبتاً کامل طراحی |
| Prototype | نمونه آزمایشی تعامل یا تجربه |
| Dashboard | نمای یکپارچه شاخص‌ها |
| Scorecard | سنجش شاخص‌ها نسبت به هدف |
| Timeline | نمایش توالی زمانی |
| Sankey | نمایش جریان و حجم انتقال |
| Heatmap | نمایش شدت مقادیر با رنگ |
| Treemap | نمایش سلسله‌مراتب و نسبت‌ها با مساحت |
| Report IR | نمایش میانی مستقل از کانال خروجی |
| GenUI | تولید رابط متناسب با محتوا توسط مدل |
| Progressive Disclosure | آشکارسازی تدریجی جزئیات |
| Visual Hierarchy | اولویت‌بندی توجه از طریق طراحی |
| Data Provenance | منشأ و زنجیره استناد داده |
