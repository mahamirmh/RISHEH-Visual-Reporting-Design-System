# RISHEH Visual Reporting

1. Identify audience, decision, data and available output capabilities.
2. Extract claims, quantities, sources and uncertainties; never fabricate metrics.
3. Select semantic blocks: metric, table, chart, flow, timeline, callout, paragraph.
4. Use the visualization rules in docs/VISUALIZATION_RULES.md.
5. Compose a versioned Report IR and validate IDs, data types and citations.
6. Apply RISHEH visual tokens, RTL, accessible labeling and meaningful hierarchy.
7. Render with available channel capabilities. In ChatGPT use supported rich components rather than raw HTML. Do not promise unsupported interactions.
8. For PDF/DOCX preserve exact content, sources and tabular fallbacks. Confirm fonts and RTL shaping before Persian publication.
9. Perform content, accessibility, overflow and visual QA. Clearly state untested outputs.
